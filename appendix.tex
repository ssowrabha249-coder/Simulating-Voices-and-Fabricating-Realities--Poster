\section{Use of Generative AI Tools}
\label{sec:ai_declaration}
The following generative AI tools were used while preparing the poster:
\begin{itemize}
    \item \textbf{Antigravity} (Google), an AI coding and writing assistant;
    \item \textbf{Claude Code} (Anthropic), with the model Claude Opus 5.5.
\end{itemize}
They were used to help draft and rephrase text, to check references and the literature numbers against the original publications, to write and debug the experiment code (Python), and to produce the LaTeX layout, the diagram and the plot. The experiment data are outputs of the open Qwen2.5 models~\cite{qwen2024qwen25} produced by that code; all experiment numbers on the poster are computed by the analysis script from the saved raw outputs (code and outputs: \repourl). The author reviewed and edited all content and takes full responsibility for it.
