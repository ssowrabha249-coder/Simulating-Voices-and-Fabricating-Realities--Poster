# Wisdom of crowds with base vs. instruction-tuned LLMs

Small replication of the *Wisdom of Crowds* Turing Experiment of Aher, Arriaga & Kalai (ICML 2023,
arXiv:2208.10264) with open models. Question: **does instruction tuning make a simulated crowd give the exact
answer with (almost) no spread, i.e. the "hyper-accuracy distortion"?**

Author: Sowrabha Somashekar (Universität Trier, M.Sc. NLP). Research poster: *Simulating Voices: Does Instruction Tuning Make a Simulated Crowd Hyper-Accurate?*.

## Design
| | |
|---|---|
| Questions | the 10 general-knowledge questions of Aher et al., Table 3 (p. 25), with true answers; human median/IQR for Q1–Q5 from the same table (`questions.json`) |
| Participants | 50 simulated people per question: 25 common surnames × {Mr., Ms.} |
| Prompt | wording of Aher et al., Fig. 14 (p. 25); valid answer = integer followed by `]` |
| Conditions | `base_raw` Qwen2.5-0.5B; `instruct_raw` Qwen2.5-0.5B-Instruct with the identical prompt; `instruct_chat` Qwen2.5-0.5B-Instruct via its chat template (first integer in the reply) |
| Sampling | temperature 1.0, top_p 1.0 (as in Aher et al., p. 7), ≤ 12 new tokens, bfloat16 on CPU; seed 1234 + question index; invalid answers re-sampled up to 10 times |
| Measures | per question: median, IQR, IQR / true value, share of exact answers; pooled exact-answer rate with stratified bootstrap 95% CI (10,000 resamples) |
| Tests | instruct vs. base: Fisher exact test on pooled exact answers; Wilcoxon signed-rank test on per-question IQR/true value (paired by question) |

## Reproduce
```bash
pip install torch transformers scipy matplotlib numpy
python test_scoring.py      # unit tests for parsing and metrics
python run.py               # writes results/raw/<condition>.jsonl (all raw completions)
python sanity.py            # completeness/ID alignment, parse rates, synthetic-crowd checks
python analyze.py           # results/summary.json, results/tables/*.csv, results/figures/*.pdf
```

## Files
- `results/raw/*.jsonl` – every completion with condition, question id, participant id, seed, tries, parsed answer
- `results/sanity_report.txt`, `results/summary.json`, `results/tables/*.csv`, `results/figures/fig_crowd_poster.pdf`
- `results/numbers.tex` – LaTeX macros with every number used on the poster (generated by `analyze.py`)
- `results/run_log_05b.txt` (base_raw), `results/run_log_instruct.txt` (instruct_raw, instruct_chat) – console logs.
  The base run and the two instruct runs were started separately (same code, same seeds per question).

## Results (from `results/summary.json`)
| Condition | Exact answers (95% CI) | Median IQR / true value | Median IQR / true, Q1–Q5 | Questions with IQR = 0 |
|---|---|---|---|---|
| base_raw | 4.0 % (2.4–5.8 %), 20/497 | 1.23 | 1.68 | 0 |
| instruct_raw | 1.4 % (0.4–2.6 %), 7/500 | 5.53 | 6.64 | 0 |
| instruct_chat | 1.0 % (0.2–1.8 %), 5/500 | 0.41 | 0.82 | 0 |
| humans (Aher et al., Tab. 3) | – | – | 0.81 | – |

Tests vs. base: Fisher exact p = 0.011 (instruct_raw), p = 0.002 (instruct_chat); Wilcoxon on spread p = 0.020
(instruct_raw, larger spread on 8/10 questions), p = 0.037 (instruct_chat, smaller spread on 9/10). Bonferroni α = 0.0125
for 4 tests. **Hypothesis (instruct = more exact + less spread) not supported at 0.5B.**
Note: for q08 (true value 299,792,458) IQR / true value is tiny for every condition and does not indicate accuracy.

## Limitations
Small models (0.5B) only, because of the available hardware (CPU, < 3 GB free RAM); one prompt; 10 questions.
Human reference values are taken from Aher et al. and were not collected here.
