## Poster content
- **Hypothesis:** aligned GPT models answer the wisdom-of-crowds questions exactly with no spread (Aher et al. 2023). H1: with the same prompt, an instruction-tuned model gives more exact answers and less spread than its base model.
- **Methodology:** Qwen2.5-0.5B vs. Qwen2.5-0.5B-Instruct; 10 questions × 50 simulated people; prompt and sampling as Aher et al.; three conditions (base, instruct, instruct via chat template); Fisher and Wilcoxon tests, Bonferroni-corrected.
- **Results:** exact answers 4.0 % (base) vs. 1.4 % / 1.0 % (instruct), no question with IQR = 0 → H1 not supported at 0.5B; the chat format narrows the spread, but around wrong values.
