# Simulating Voices: Does Instruction Tuning Make a Simulated Crowd Hyper-Accurate?

Research poster, NLP module, M.Sc. Natural Language Processing, Universität Trier.
**Author:** Sowrabha Somashekar · **Supervisor:** Dr. phil. Simon Werner

A replication of the wisdom-of-crowds Turing Experiment (Aher et al. 2023) with Qwen2.5-0.5B vs. Qwen2.5-0.5B-Instruct.
Result: instruction tuning alone did **not** make the simulated crowd hyper-accurate.

- `poster.pdf`: the poster
- `appendix.pdf`: references, AI-use statement, declaration
- `experiment/`: code, questions, all raw model outputs and results (see [experiment/README.md](experiment/README.md))
