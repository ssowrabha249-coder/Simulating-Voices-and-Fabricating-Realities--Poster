# Simulating Voices: Does Instruction Tuning Make a Simulated Crowd Hyper-Accurate?

Research poster, NLP module, M.Sc. Natural Language Processing, Universität Trier.
**Author:** Sowrabha Somashekar (Matr. 1837734) · **Supervisor:** Dr. phil. Simon Werner

A replication of the wisdom-of-crowds Turing Experiment (Aher et al. 2023) with Qwen2.5-0.5B vs. Qwen2.5-0.5B-Instruct.
Result: instruction tuning alone did **not** make the small simulated crowd hyper-accurate (H1 not supported).
Code, the 10 questions and all 1,500 raw model outputs are in [`experiment/`](experiment/README.md).

## Files
| File | Purpose |
|---|---|
| `poster.tex` → `poster.pdf` | the poster (DIN A1, 1 page) |
| `appendix.tex` → `appendix.pdf` | references (`references.bib`), AI-use statement, declaration |
| `declaration/` | official declaration form, pre-filled |
| `experiment/` | experiment code, raw outputs, analysis results |
| `1837734.zip` | submission archive (`poster.pdf` + `appendix.pdf`) |
| `verify_poster.py`, `make_submission.py` | poster checker and ZIP builder |

Experiment numbers on the poster are LaTeX macros from `experiment/results/numbers.tex` (generated by `experiment/analyze.py`); the figure is `experiment/results/figures/fig_crowd_poster.pdf`.

## Build
```bash
pdflatex poster
pdflatex appendix && bibtex appendix && pdflatex appendix && pdflatex appendix
python verify_poster.py      # 1 page, DIN A1, smallest font >= 24 pt, image PPI, repository link
python make_submission.py    # writes 1837734.zip
```
Requires LaTeX (beamer, beamerposter, tcolorbox, TikZ) and Python with `pdfplumber`.
